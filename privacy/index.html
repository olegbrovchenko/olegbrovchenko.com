Privacy Policy

Last updated: 25 September 2026

This page covers two things: this website, olegbrovchenko.com, and YouTube Analytics MCP, a private tool I built to read the analytics of my own YouTube channel. The site and the tool are run by Oleg Brovchenko (Full Drill Production S.L., Madrid, Spain).

This website

olegbrovchenko.com is a static portfolio. It has no accounts, no forms, no analytics and no advertising cookies. The music videos are embedded from YouTube. When you play one, YouTube (Google) may process data under Google's Privacy Policy. The site is hosted on GitHub Pages, which may keep standard server logs such as IP addresses for security.

YouTube Analytics MCP

YouTube Analytics MCP is a personal tool. It is not offered to the public, and the only Google account that signs in to it is my own. It uses YouTube API Services.

What it accesses. After I sign in with Google and grant access, it reads the analytics of my own channel (views, watch time, traffic sources, audience and retention reports) and my own video metadata. It can also update the descriptions of my own videos when I ask it to. It uses these Google scopes:

  • https://www.googleapis.com/auth/yt-analytics.readonly
  • https://www.googleapis.com/auth/youtube.force-ssl

How the data is used. Only to show me my own channel's numbers and help me plan my content. The data is not sold, not shared with third parties, not used for advertising and not used to train any model.

Where it is stored. The sign-in token is stored only on my own computer. Analytics results are fetched on demand and are not kept in any external database.

How to revoke access. Access can be removed at any time from Google Account permissions. Deleting the local token deletes everything the tool holds.

By using this tool you are also bound by the YouTube Terms of Service and Google's Privacy Policy. The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
